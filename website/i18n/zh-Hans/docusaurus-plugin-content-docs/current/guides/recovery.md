# 升级、撤销与恢复

更换设备或删除状态之前，先确认独立恢复身份可以解密每个要保留的测试文件。恢复必须不依赖原手机、电脑硬件密钥或插件状态。仅有公开存根，或仅在同一电脑上配对第二部手机，都不能提供这种保护。

## 升级时保留配对

安装兼容的桌面版本与对应手机版本，保留应用数据和电脑状态。Beta 2 的多身份修复不要求从 Beta 1 重新配对或迁移状态。更新后验证手机和恢复两种解密。不要为了排查签名冲突而卸载手机应用、清除其数据或创建替代身份。

`cargo uninstall age-plugin-phone` 只删除可执行文件，不删除配对状态。重新安装不能恢复丢失的硬件密钥。不要从旧快照恢复重放状态文件、通过设备迁移工具复制配对状态，或删除待处理标记来让请求继续。Windows 和 macOS 不保证检测到旧的有效电脑重放快照被恢复。

## 恢复中断的配对

仅当完整指纹已经确认并被持久记录时，才恢复该次操作：

```sh
age-plugin-phone setup --resume
```

如果公开文件以 tag 创建，重复添加 `--recipient-type tag`。如需放弃未完成的操作：

```sh
age-plugin-phone setup --cleanup
```

清理会删除日志中记录的确切未完成操作。检查显示的指纹或配对代码，并亲自输入确认。如果手机已经提交配对，还需在手机上撤销对应记录。这两个命令都不会重置状态不确定的重放存储。如果状态损坏或命令拒绝继续，请停止并阅读[故障排查](../troubleshooting.md)。

## 撤销并移除配对

以下操作具有破坏性。先验证独立恢复。在手机的 **Paired desktops** 中选择目标条目，比较完整指纹并完成原生撤销确认。然后删除电脑状态：

```sh
age-plugin-phone remove-desktop-state --identity-stub '<identity-stub-path>'
```

检查并输入完整指纹。命令删除该配对的确切本地状态和指定公开存根，不会远程撤销手机。若中断，使用相同存根路径重复相同命令；它只恢复日志中记录的目标。

如果存根已经不可用，先识别受保护配置根目录直接子级中的确切规范定位文件，再使用仅用于恢复的孤立状态清理：

```sh
age-plugin-phone remove-orphaned-desktop-state --locator '<absolute-locator-path>'
```

不要使用通配符，也不要按电脑标签猜测。该命令不查找或删除公开存根，也不撤销手机配对。尽可能优先使用基于存根的清理。macOS 删除本地密钥引用，不代表同一 Mac 上复制过的所有引用都被销毁；手机侧撤销才是最终依据。

## 更换设备或删除手机身份

重新配对不能恢复旧的 v2 密文。停用任一端之前：

1. 使用仍可工作的原配对，或最初加密时已加入的独立恢复收件人，解密要保留的测试文件。
2. 配对新设备，向新收件人和独立恢复收件人重新加密。
3. 验证两条路径后，再撤销旧配对或删除旧手机身份。

手机身份删除会在原生破坏性确认后移除其配对和密钥。如果手机丢失，本地清理仍不等于手机撤销。如果原加密没有包含任何仍可用的收件人，重新配对无法恢复文件。更改收件人也不会撤销对旧密文副本的访问。
