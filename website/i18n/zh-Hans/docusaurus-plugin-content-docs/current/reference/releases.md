# 版本与已知限制

本手册适用于 **0.1.0-beta.2**，这是于 2026 年 9 月 11 日发布的有限技术测试版。仅使用可丢弃或合成数据。协议 v2 尚未冻结；发布不会扩大硬件验收范围，也不代表可以保护真实秘密。

## Beta 2

[GitHub 发布页](https://github.com/biulight/age-plugin-phone/releases/tag/v0.1.0-beta.2)提供已签名的 Android ARM64 APK、测试签名的 Windows x64 ZIP、校验文件和签名验证记录。Windows 与 macOS 在满足各自构建条件后，可以从 crates.io 安装固定版本 CLI。不提供外部 iOS 分发。

Beta 2 修复了标准 age 多身份配置中遇到不匹配但有效的 v2 phone 身份后无法继续的问题。协议 v2、收件人编码、密钥保管和配对格式均未改变；从 Beta 1 升级本身不需要重新配对。损坏状态和格式错误的受支持密文段仍是致命错误；选中配对后失败不会切换配对。

不可变 tag 和发布正文保留了发布前的候选措辞。已发布附件和当前仓库发布记录确认其已经发布；这些旧措辞不代表额外的支持承诺。

## 保留的限制

- 每次解包都需要新的手机原生验证，没有缓存授权或无人值守模式。
- Windows ZIP 使用私有测试根证书，不是公开可信签名。不要将该根证书加入系统信任库。
- 源码真机验收不能证明确切的 Windows/Android 发布包组合通过验证。使用该组合重复 Beta 2 多身份回归仍待完成。
- macOS 验收限于已记录的硬件。其他系统版本、Intel/T2、图形调用程序和更广的生命周期、设备组合尚未验证。
- Wi-Fi 仅支持前台，仍属实验性。BLE 不可用。QR/tag 真机覆盖和更广的多手机覆盖仍不完整。
- Windows/macOS 不保证检测到旧的有效电脑重放快照被恢复。不要通过恢复重放状态来修复故障。
- 更换手机或电脑需要独立恢复与重新加密；新配对不能恢复旧 v2 密文。

## 早期版本

Beta 1 引入显式原生 tag 收件人；Beta 2 仍默认使用 `phone`。Alpha 指南与验收记录描述历史范围。当前操作使用本手册的稳定路由，兼容性见[收件人选择](../guides/recipients.md)，更改状态前阅读[恢复指南](../guides/recovery.md)。延期检查仍未完成，不能当作已通过。
